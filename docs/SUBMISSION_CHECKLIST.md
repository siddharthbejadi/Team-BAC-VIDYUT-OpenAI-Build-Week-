# OpenAI Build Week submission checklist

Deadline verified from Devpost: **Tuesday, July 21, 2026 at 5:00 PM Pacific Time** (2026-07-22 00:00 UTC).

## Build

- [x] Working, runnable project
- [x] Three-machine guided demo
- [x] Deterministic evidence export
- [x] Optional GPT-5.6 integration and no-key testing path
- [x] Automated tests and sample data
- [x] Installation and testing instructions
- [x] Devpost cover image
- [x] Put the project in a local Git repository and commit the final code
- [ ] Deploy a demo URL, or give judges the local testing path from `README.md`

## Required Devpost fields

- [ ] Submitter type: Individual, Team of Individuals, or Organization
- [ ] Country of residence
- [ ] Category: **Developer Tools**
- [ ] Code repository URL
- [ ] `/feedback` Codex Session ID from this primary build task
- [ ] Public/unlisted YouTube demo URL under three minutes
- [ ] Description reviewed and personalized from `DEVPOST_DRAFT.md`

## Video compliance

- [ ] Shows the project working
- [ ] Voiceover explains what was built
- [ ] Voiceover explains how Codex was used
- [ ] Voiceover explains how GPT-5.6 was used
- [ ] Link opens in an incognito/private browser
- [ ] Duration is below 3:00

## Repository compliance

- [ ] Public repository includes the MIT `LICENSE`, or private repository is shared with `testing@devpost.com` and `build-week-event@openai.com`
- [ ] README setup works from a fresh checkout
- [ ] No `.env`, API key, token, credentials, or private customer material is committed
- [ ] If working with teammates, all Devpost invitations are accepted before the deadline

## Final submission

- [ ] Select Developer Tools
- [ ] Add the required form answers
- [ ] Submit—not just save as a draft
- [ ] Reopen the submission and verify its video, repository, cover, description, and status
